# TEA_Model

Techno-economic analysis (TEA) work for ENGG 192: LCA/TEA of sodium-ion battery electrolytes (solid-state and gel polymer).

## Contents

| File | What it is |
|---|---|
| `index.html` | Process flows for the NaPF₆ liquid baseline and oxide (NASICON), sulfide, halide and PEO–PPC–NASICON composite electrolytes, with LCA/TEA hotspots, a worst-case H₂S bound and a per-kWh electrolyte cost calculator. Open in any browser. |
| `NaEV_Julian_TEA_tables.xlsx` | Julian Chitu's Na-ion EV pack TEA ("NA EV" TEM project) rebuilt with live formulas: Inputs, PFD mass balance, CapEx, OpEx, cash flow and sensitivity, plus the Argonne reference tables and a list of model issues. Values were transcribed from his slides. |

## Notes

- Temperatures, thicknesses and $/kg values in `index.html` are illustrative placeholders, not cited values.
- In the spreadsheet, blue cells are inputs, black cells are formulas, and the "Julian's value" columns hold his original numbers for comparison.
